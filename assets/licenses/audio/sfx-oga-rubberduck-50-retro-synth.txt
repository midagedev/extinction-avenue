Description (verbatim, tags stripped):
I made 50 retro / synth effects with LMMS using mostly the ZynAddSubFX synthesizer. It includes power up, coin, death/die, explosion, shoot, beep, laser and other misc sounds. Also in the package included are source files, which can be opened with lmms. So you can change parameters of the effect to make it sound different. All synth effects are made from scratch, they are NOT based on presets that comes with lmms.
